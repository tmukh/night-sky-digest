# Retrieval eval

How the eval set is built (decision: [ADR 0003](../docs/adr/0003-llm-generated-eval-set.md)):

1. **Queries**: `queries.yaml`, 60 English and 20 German, generated by Claude from the prompts in
   [prompts/](prompts/), checked automatically (counts per subfield and kind, duplicates, overlap with
   corpus titles). Each query has an `intent` that defines relevance.
2. **Pool**: top 20 from lexical, semantic and hybrid search per query, merged.
3. **Judge**: two local Ollama models label each pooled paper 0 (not relevant), 1 (partly), 2 (relevant).
4. **Resolve**: where the two judges differ, a third (`llama3.1:8b`) grades too; the median wins.
   A random sample of 30 final labels is audited by hand.
5. **Metrics**: recall@10, nDCG@10, MRR.
6. **CI gate**: `snapshot/` freezes the 1,551 pooled papers, 2,000 random distractors, their bge-m3
   embeddings (float16) and the query embeddings, about 9 MB. CI loads it into its Postgres container
   and runs `python -m night_sky_digest.evals gate`, which fails if hybrid recall@10 or nDCG@10 drops
   more than 0.02 below `baseline.json`. After an intended improvement, run `gate --update-baseline`
   and commit the new baseline with the change that caused it.

**Leakage check** (2026-10-10): word overlap (Jaccard) between each query and all 51,282 corpus titles.
Median 0.36, maximum 0.80 (q040 "fast radio bursts not from magnetars" vs "Escape of fast radio bursts
from magnetars", which shares topic words but claims the opposite). No query looks like a paraphrased title.

## Label quality (2026-10-11)

| Comparison | Exact grade | Relevant (grade ≥ 1) or not | Cohen's kappa |
|---|---|---|---|
| qwen2.5:7b vs gemma4:12b, all 1,571 pairs | 65.3% | 83.4% | 0.47 (0.63 binary) |
| Human audit vs final labels, 30 random pairs | 90% | 97% | 0.81 |
| Human audit vs qwen2.5:7b alone | 67% | 90% | 0.45 |
| Human audit vs gemma4:12b alone | 83% | 97% | 0.65 |

1,026 labels came from agreement, 545 from the tie-break. Caveats: 30 audited items is a small sample
(29/30 binary agreement still allows a true rate of roughly 83–99%), the auditor is not an astrophysicist,
and the audit sheet showed the judges' reasons, which can anchor the auditor. Reproduce with
`python -m night_sky_digest.evals audit-report`.

## Results (2026-10-11, k = 10, 80 queries: 60 English, 20 German)

| Mode | recall@10 | nDCG@10 | MRR |
|---|---|---|---|
| lexical | 0.16 | 0.34 | 0.53 |
| semantic | 0.51 | 0.69 | 0.90 |
| hybrid | 0.53 | 0.72 | 0.91 |

| Language | lexical nDCG@10 | semantic nDCG@10 | hybrid nDCG@10 |
|---|---|---|---|
| English (60) | 0.45 | 0.69 | 0.74 |
| German (20) | 0.00 | 0.67 | 0.67 |

- Full-text search stems English, so it finds nothing for German queries; for German, hybrid is pure
  vector search. bge-m3 crosses languages almost without loss (semantic 0.67 vs 0.69).
- Five German queries translate English ones. Scored against the English query's labels, German
  averages nDCG@10 0.51 vs 0.64 for English: identical where German keeps the English term ("Little Red
  Dots"), much worse for casual German compounds ("babyplaneten ..." 0.30 vs 0.82). Five pairs only.
- Lexical collapses on contrarian (nDCG 0.02), synonym (0.05) and question (0.17) queries; on question
  and contrarian queries semantic alone beats hybrid, because RRF still mixes in weak lexical hits.
- Median 17 relevant papers per English query, so recall@10 is capped well below 1 (0.64 for English).
  German pools are smaller (no lexical hits), so German recall is not comparable to English recall.
- Pooled judging: relevant papers none of the three modes found are unknown, so recall is somewhat
  overestimated.

CI gate baseline (frozen snapshot, 80 queries): hybrid recall@10 0.524, nDCG@10 0.719.
